# mediconnect-admin

Next.js administration and clinic console for MediConnect.

**Phase 1: placeholder only.** Login, MFA, overview, user management, RBAC, audit logs, system configuration, doctor verification and clinic administration are planned for Phase 2 (scope decision 2026-11-18, `mediconnect-docs/docs/development-roadmap.md`).

```bash
pnpm install
pnpm dev          # http://localhost:3001
pnpm typecheck && pnpm lint && pnpm build
```
